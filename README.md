# nczempin.github.io

## What Problem Does This Solve?

It provides a public-facing web presence and navigation point for visitors interested in exploring the developer's work, particularly the Turres Monacorum game project.

## Setup Instructions

### Prerequisites
- Git for version control
- Basic HTML/CSS knowledge for site modifications

### Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/nczempin/nczempin.github.io.git
   cd nczempin.github.io
   ```

2. Make changes to the HTML/CSS files locally.

3. Test changes by opening the HTML files in a web browser.

### Deployment
GitHub Pages automatically deploys the site when changes are pushed to the main branch:

```bash
git add .
git commit -m "Update website content"
git push origin main
```

The site will be available at: https://nczempin.github.io
